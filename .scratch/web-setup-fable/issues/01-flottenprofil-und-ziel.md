Type: grilling

## Question

Gilt 'nur Opus, Sonnet, Haiku' dauerhaft oder nur bis die Proxy-Routen zurück sind? Darf Sonnet als read-only Kritiker gelten (Arbeitsvertrag §3 sagt heute 'Sonnet nie Worker')? Wer schreibt Copy ohne Kimi/Sol: Opus im eigenen Leaf mit Sonnet-Judge? War das Opus-Copy-Verbot ein Qualitätsurteil oder nur die Familienregel? Ist das Ziel das ganze Setup (Skill + Arbeitsvertrag + Pipeline + Pilot)? Default: dauerhaft mit Schalter, Sonnet kritisiert, Opus schreibt Copy im eigenen Leaf, Ziel = ganzes Setup.

Ergänzung aus Synthese §5: E1 Kritik ohne Fremdfamilie (Weg A Instanz-Trennung als ausdrücklich schwächere Garantie, oder Weg B BLOCKED bis fremde Familie da ist); E2 Copy-Deadlock (Opus-Ausnahme benannt in SKILL.md Rote Linie 6, oder Copy als Input von aussen). Default: Weg A mit sichtbarem Label "claude-only, Instanz-Trennung"; Opus-Ausnahme für Copy.

## Answer

Raphael 02.09.2026: alle Defaults gelten. Profil claude-only dauerhaft mit Schalter; Fable Controller, Opus baut, Sonnet kritisiert read-only, Haiku nur Ledger/Masse. Kritik ohne Fremdfamilie = Weg A: Instanz-Trennung (Kritiker sieht nur Shots + PRUEFGEGEN.md, nie den Build-Verlauf) mit sichtbarem Label 'claude-only, Instanz-Trennung' als ausdrücklich schwächere Garantie; deterministische Gates werden zum Urteil hochgestuft. Copy: Opus im eigenen Copy-Leaf (nie der Integrator-Leaf), G0/G1 im Leaf, Sonnet judged G2. Ziel = ganzes Setup (Skill, Arbeitsvertrag §3, Pipelines, Pilot).
