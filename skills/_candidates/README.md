# _candidates/ — Skill-Kandidaten (noch nicht aktiv)

Ablage fuer `extract-approach` ("skillify this"): ein Muster, das zum zweiten Mal
in echter Arbeit auftaucht, landet hier als Kandidat — NICHT als aktiver Skill.

Regeln:
- Nie direkt nach `eigene/`, `ops/`, `methodik/` etc. verschieben ohne Raphaels
  Freigabe (Skill-Mutation ist Rot-Klasse, siehe `AGENTS.md` im Command-Center).
- Vor dem Anlegen eines neuen Kandidaten prüfen, ob es hier schon einen gibt
  (keine Duplikate).
- Format: `<name>/SKILL.md` nach `eigene/extract-approach/references/candidate-template.md`.

Aktuell leer (Stand skills v1) — kein Kandidat wurde bislang 2x wiederholt beobachtet.
