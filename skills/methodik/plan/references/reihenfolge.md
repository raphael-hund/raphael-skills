# Drei-Framework-Reihenfolge

Drei Planungs-Frameworks liegen im Setup nebeneinander: `grill` (Pocock-Stil
Ausrichtung), `superpowers` (brainstorm→spec→tasks→parallele Subagents→review)
und `gstack` (spec→build→Review-Rollen→QA→ship). Ohne feste Reihenfolge
laufen leicht zwei konkurrierende State-Maschinen auf demselben Task.

Reihenfolge bei neuen Vorhaben: erst `grill` (Ausrichtung, Pocock-Stil,
"was will Raphael wirklich"), dann `superpowers` (brainstorm→spec→tasks→
parallele Subagents→review) ODER `gstack` (spec→build→Review-Rollen→QA→ship)
für den Bau — nie beide gleichzeitig auf denselben Task, sonst zwei
konkurrierende State-Maschinen.
