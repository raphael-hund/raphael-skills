# methodik/ — Methodik-Skills

Platzhalter. Noch kein Methodik-Skill angelegt (Stand skills v1).

Gehoert hierher: genau EIN aktives Methodik-Framework (z. B. ein superpowers-Subset
nach Vendoring in `imported/`, dann hier als schlanker Router-Skill referenziert) —
Vorgehensweisen, die skill-uebergreifend gelten (z. B. draft->test->evaluate->iterate,
WIP=1, Fresh-Session-Test). Nicht kombinieren: gstack/ECC etc. liefern nur Muster,
die in `AGENTS.md` einfliessen, nicht als eigener Methodik-Skill.

Bauordnung wie jeder andere Skill: `SKILL.md` mit Pflicht-Frontmatter
(`name`, `version`, `description`, `completion_criteria`), siehe README.md im
Repo-Wurzelverzeichnis.
