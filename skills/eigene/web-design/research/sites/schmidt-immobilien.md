### Die 5 staerksten Muster

**1. Ein Funnel-Ziel, ueberall derselbe Link.** Auf Home 5x `Immobilienbewertung starten`, auf der Verkaufsseite 6x, auf der Stadtteilseite 7x, alle auf `/immobilienbewertung/`.
Beleg: `home.html` `<span class="elementor-button-text">Immobilienbewertung starten</span>` mit `href="/immobilienbewertung/"`.

**2. Stadtteilseiten als Klon der Startseite mit drei getauschten Bloecken.** Identisches Geruest, identisches Karussell mit Template 881, identische Badge-Reihe, identischer Einzugsgebiet-Block mit denselben 43 Ortslinks. Getauscht werden nur H1, Hero-Absatz, Marktblock und FAQ-Fragen.
Beleg: `lindenthal.html` und `home.html` enthalten beide `<div class="elementor-element elementor-element-5ea3140 e-flex e-con-boxed e-con e-child">` mit `<h2 class="elementor-heading-title elementor-size-default">Unsere Immobilien</h2>`.

**3. Glass-Card-Marquee als Prozessdarstellung.** Statt einer statischen Schrittliste laeuft eine vertikale Kartenkolonne in einer 320px-Spalte ueber dem Prozessbild, mit Backdrop-Blur und weissem Rand.
Beleg: Inline-Style in `home.html`, `.immo-card{background:var(--glass-bg);-webkit-backdrop-filter:blur(var(--blur-amount));backdrop-filter:blur(var(--blur-amount));box-shadow:0 1px 0 rgba(255,255,255,0.5) inset,0 8px 20px rgba(0,0,0,0.08)}` und `.immo-marquee-track{animation:marqueeScroll var(--scroll-duration) linear infinite}`. Der Trick fuer den nahtlosen Loop steht als Kommentar im Code: `/* Exakt -50% dank symmetrischem Padding → nahtlos */`.

**4. Semantisches HTML statt JavaScript-Akkordeon.** Die FAQ-Bloecke auf Verkaufs- und Stadtteilseiten sind native `<details>` aus Elementor Pro mit korrektem `aria-expanded` und gestaffeltem `tabindex`.
Beleg: `verkaufen.html` `<details id="e-n-accordion-item-2030" class="e-n-accordion-item" > <summary class="e-n-accordion-item-title" data-accordion-index="1" tabindex="0" aria-expanded="false" aria-controls="e-n-accordion-item-2030" >`.

**5. Ortslinks als Sitemap im Body statt nur im Footer.** Ein Block `Unser Einzugsgebiet` mit 43 internen Links auf vier H2-Gruppen, auf jeder kommerziellen Seite wiederholt.
Beleg: `home.html` Icon-List-Texte `['Immobilienmakler Agnesviertel', 'Immobilienmakler Belgisches Viertel', 'Immobilienmakler Braunsfeld', 'Immobilienmakler Ehrenfeld', 'Immobilienmakler Hürth', 'Immobilienmakler Junkersdorf', ...]`, identisch in `verkaufen.html` und `lindenthal.html`.

### Animation-Rezepte

**Rezept 1: Vertikale Glass-Card-Marquee, exakt wie auf der Seite**
```css
:root { --track-gap:16px; --scroll-duration:30s; --card-width:320px; --blur-amount:20px; }

.marquee-track {
  display: flex; flex-direction: column;
  row-gap: var(--track-gap);
  padding-block: calc(var(--track-gap) / 2);   /* symmetrisch, damit -50% nahtlos passt */
  animation: marqueeScroll var(--scroll-duration) linear infinite;
  will-change: transform;
  transform: translate3d(0,0,0);
}
@keyframes marqueeScroll {
  0%   { transform: translate3d(0, 0, 0); }
  100% { transform: translate3d(0, -50%, 0); }
}
.marquee-inner:hover .marquee-track { animation-play-state: paused; }
.card {
  gap:14px; padding:14px 18px;
  background: rgba(255,255,255,0.7);
  border: 1px solid rgba(255,255,255,1);
  border-radius: 8px;
  backdrop-filter: blur(20px); -webkit-backdrop-filter: blur(20px);
  color:#343434;
  box-shadow: 0 1px 0 rgba(255,255,255,0.5) inset, 0 8px 20px rgba(0,0,0,0.08);
}
@media (prefers-reduced-motion: reduce) { .marquee-track { animation-duration: 60s; } }
@media (max-width: 480px) { :root { --badge-size:40px; --track-gap:12px; } }
```
Wichtig: der Inhalt muss genau zweimal im Track liegen, sonst springt der Loop.

### Anti-Patterns und Schwaechen

1. **Leere `alt`-Attribute, und wo Text steht, ist er nutzlos.** 12 der 22 Bilder im Main der Startseite haben `alt=""`, darunter alle Objektfotos im Karussell und das Hero-Foto. Die uebrigen 10 sind die zehn Kopien desselben Marquee-Bildes mit dem nichtssagenden Text `Image gallery marquee`.
2. **Lorem-Ipsum im Live-HTML.** Auf `/ratgeber/immobilienpreise-koeln/` im Kontaktblock: `Lorem Ipsum is simply dummy text of the printing and typesetting industry. Lorem Ipsum has been the industry's standard dummy text ever since the 1500s...`
3. **H1 und H2 sind gleich gross.** Beide 48px, beide Libre Baskerville 400. Die Hierarchie ist visuell nicht lesbar.
4. **Hero ohne Trust-Signal.** Keine Google-Note, keine Objektzahl, kein Siegel im sichtbaren Bereich, obwohl "Über 200 erfolgreich vermittelte Objekte" und "ImmobilienScout Silver Partner" vorhanden sind, aber erst nach fuenf Sektionen.
5. **Kein FAQPage-Schema.** 0 Treffer fuer `FAQPage` in allen 10 geprueften Seiten, obwohl auf drei Seiten FAQ-Inhalte stehen. Google kann die Fragen nicht als Rich Result lesen.
6. **Drei Seiten teilen denselben Title.** `/immobilienbewertung/`, `/ueber-uns/`, `/ratgeber/`, `/referenzen/`, `/immobilienangebote/`, `/kontakt/` haben das Muster `X - Schmidt Immobilien Köln`, sechs Seiten mit austauschbarem Title und ohne Meta-Description.
7. **Doppelter H2 auf einer Seite.** `verkaufen.html` hat `Käuferprüfung – Sicherheit für Eigentümer` zweimal, in Sektion 7 und Sektion 8.
8. **Zwei GA4-Properties parallel.** `GT-K4V8CH35` per Site Kit plus `G-C5WNL16X6S` aus dem Fremd-Badge. Das erzeugt doppelte Seitenaufrufe.
9. **Reduced Motion nur halb umgesetzt.** Die Marquee wird bei `prefers-reduced-motion: reduce` verlangsamt, nicht gestoppt. Swiper, Grow-Animation und Motion Effect ignorieren die Einstellung ganz.
10. **Fremd-Web-Component im Funnel ohne Fallback.** `/immobilienbewertung/` hat ohne JavaScript genau null Inhalt, kein `<noscript>`, keine Server-Formularvariante.
11. **Objektkarten ohne `srcset`** im Karussell, obwohl die Bilder bis 2560px breit geladen werden.
12. **Uncategorized als einzige Kategorie.** `sm-category.xml` enthaelt genau eine URL: `/ratgeber/category/uncategorized/`. Keine thematische Struktur fuer 10 Artikel.
13. **Reparaturbeduerftige interne Links.** Auf der Startseite stehen `href="/immobilienmakler-koeln-schmidt-immobilien-lokal-kompetent"` mit 301 auf `/`, `/immobilien-huerth%20` und `/wohnung-kaufen-in-huerth%20` mit Leerzeichen im Pfad, `/immobilie-verkaufen-frechen/%20`, und ein Gross-Klein-Mischling `/Immobilienmakler-lindenthal`. Die Liste enthaelt auch `/immobilienmakler-klettenberg/` und `/immobilienmakler-loevenich/`, die auf der Startseite in keiner Ortsliste verlinkt sind, und `/immobilienmakler-marienburg` verlinkt ohne Trailing Slash, die Sitemap fuehrt `marienburg`. In der Startseiten-Ortsliste steht `Immobilienmakler Pulheim` mit `href="/immobilienmakler-pulheim"`, die Zielseite liefert 200, liegt aber nicht im `page-sitemap.xml`.
14. **`articleSection: ["Uncategorized"]`** im Article-Schema trotz klarer thematischer Zuordnung.
15. **Autor-Metadaten widerspruechlich.** `meta name="author"` ist `adminseolabs`, die Autor-Box nennt Elke Schmidt, das Schema-Person-Objekt heisst ebenfalls `adminseolabs`.

### Conversion-Mechanik

Die Seite baut keinen Kaufdruck auf, sondern verlagert den ersten Schritt auf eine kostenlose Wertermittlung. Jede kommerzielle Seite traegt denselben Button `Immobilienbewertung starten`, auf Home fuenfmal, auf der Verkaufsseite sechsmal, auf der Stadtteilseite siebenmal, immer auf `/immobilienbewertung/`. Der Funnel dort verlangt in zehn Schritten erst Objekttyp, dann Untertyp, dann Details wie `Anzahl der Zimmer` und `Baujahr`, dann den Zustand, dann die Adresse mit `PLZ`, und erst danach die E-Mail. Telefonnummer kommt noch spaeter mit separater Verifikation, sodass der Nutzer bis zum Kontaktschritt bereits mehrere Minuten investiert hat. Wer nicht den Funnel nimmt, landet ueber `Kostenlose Beratung` oder den Header-Button `Kontakt` auf einem Acht-Felder-Formular mit Button `Abschicken`. Die Ueberzeugungsarbeit davor laeuft ueber Risiko-Angst (Sektion `Risiken ohne Makler`) und lokale Autoritaet (43 Ortslinks plus 16 Stadtteilseiten), nicht ueber Preis oder Garantie.
