# Per-Section Spec Template

Eine Datei pro Seite unter `06-seiten/<slug>.md` — Copy + alle Sections.

```markdown
## Section: [Name]

### Zweck
- Nutzerfrage / JTBD:
- Rolle im Conversion-Fluss:
- Priorität: kritisch | wichtig | optional

### Finale Copy (humanisiert; FINAL erst nach PLAN_VERIFIED)
- Eyebrow:
- H1/H2:
- Body:
- Bullets:
- CTA primary (Label + Ziel):
- CTA secondary:
- Microcopy / Captions:

### Layout
- Composition (bewusst — nicht default immer Text-links/Bild-rechts):
- Desktop:
- Mobile stack / Reihenfolge:
- Container / Spalten / Gaps (Idee + Token-Stufe):
- Padding top/bottom (Stufe: compact | default | airy | hero):
- Max. Textbreite:
- Background: solid | texture | gradient | full-bleed photo | pattern | map | none
- Overlay / Kontrast:

### Components
- Repo-Components:
- Neu (Begründung):
- Library-Inspiration (Name + was geklaut wird strukturell):

### Buttons & Interaktion (Vision, nicht nur Name)
- Variant / Größe:
- Label:
- Hover-Idee (z.B. Glow, Farbshift, Lift, Underline):
- Focus-visible:
- Active / Disabled / Loading:
- Mobile sticky CTA: ja/nein

### Header-Bezug
- transparent over media / solid / shrink on scroll:

### Icons
- Set (z.B. Lucide): Größe / Stroke / Farbe / Container
- Liste Icons in dieser Section (oder „keine“):

### Illustration / Foto
- Foto aus Inventar: [datei] + Alt-Text final
- oder Illustration-Brief:
- oder Gap-Task:

### Motion
- Trigger:
- Element:
- Initial → Final:
- Dauer (ms):
- Easing:
- Stagger (ms oder 0):

### SEO
- Heading-Level:
- Internal links (Ziel + Anchor):
- Schema-Beitrag:

### Mockup-Brief
- Section-Index (x von n):
- Composition anchor:
- Background mode:
- Visual-Reference-IDs (primär/sekundär + jeweilige Modellrolle):
- Nicht übernehmen:
- Exact copy block (copy-paste):
- „Konzept-Layout, exact copy, kein Lorem“

### Review
- Gauntlet ok:
- Offene Blocker:
- Copy-Status: READY_FOR_VERIFY | OWNER_BLOCKED | VERIFIED
```

Alle Überschriften dieses Templates sind pro sichtbarer Section Pflicht. Verweise wie
„wie oben“, „analog zu Section X“ oder ein Sammel-Spec am Dateiende sind FAIL.
