# Copy-Archetyp-Menü (lernen, nicht klonen)

Mechanik ist fest. Referenz-URLs pro Job austauschbar.

## So wählen

1. Ticket-Höhe + Unsicherheit  
2. Ehrlich: welche Proof-Lage haben wir?  
3. Primärer CTA-Typ (Rechner / Angebot / Gespräch / Anruf)  
4. Ein Ton-Regler  

Output in `05b-copy-style.md`: **1 Primär-Archetyp + optional 1 Mix** + 3 Zeilen Begründung.
