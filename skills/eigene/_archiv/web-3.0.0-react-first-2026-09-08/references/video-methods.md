## Apply the useful pattern to production

1. **Retrieve for fit.** Search accessible references using the offer, audience, tone, content density and required page type. Inspect candidate designs and identify the selected source. Discover an existing MotionSites connection if relevant; otherwise use legitimately accessible examples. Record unavailable access and continue with the supplied references.
2. **Extract a contract.** Translate the chosen direction into DESIGN.md: typography, spacing, image roles, composition, responsive transformations and motion states. Record what is retained and what changes for this brand. A template's copy, industry, pricing and claims never become client facts.
3. **Separate imagery from layout decisions.** Establish subject matter, crop and colour treatment before producing assets. Preserve real business evidence. Reinspect the composition after replacement images load; new imagery can change contrast, hierarchy and spacing requirements. The WellWorks example shows separate horizontal cards as windows onto one continuous photograph. Preserve a shared image origin and scale when implementing that selected effect; independent `cover` crops per card can break continuity. Verify text contrast and mobile crops after image integration.
4. **Convert preview into evidence.** Capture the actual running implementation at matched desktop and mobile widths, then inspect full-page rhythm and section details. Use separate state captures or recordings for motion and interactive controls. Compare against the recorded contract, fix concrete defects, and recapture affected views. This review loop is our requirement; the source's browser preview does not prove it occurred.
5. **Expand to the agreed website.** Carry the shared system across actual SEO subpages and working visitor journeys. Independently verify rendered content, links, metadata, forms, accessibility and performance. Treat batch concepts as exploration until each site passes its own delivery gates.

## Production adaptations from these tutorials

**Prepare references without altering QA evidence.** If competing imagery would confuse a reconstruction request, make a labelled prepared reference copy: mask the replaceable region with the observed surface colour and annotate the slot. Preserve the original and record the preparation. This is an intentionally altered design input, never a replacement for untouched implementation screenshots. Follow [screenshots.md](screenshots.md) for capture and retest evidence; use [design-contract.md](design-contract.md) to record the adaptations.

**Choose structured or raster input deliberately.** Use genuine Figma components, tokens and layout when available; inspect exported code rather than trusting its responsiveness. A screenshot pasted into Figma remains raster imagery, not editable layout structure. Prefer original illustration exports; when raster capture is necessary, check crop, transparency, pixel dimensions and weight. Map filenames to named asset slots. Record aspect ratio, focal area, background and responsive crop; upload order alone is fragile.

**Correct the governing constraint.** Name the affected section, destination, shared container and styles to preserve. After a failed edit, inspect parent width, padding, grid alignment, clipping or media fit and make a measurable correction. Reuse approved components before importing another treatment. Tutorial-specific heights and export multipliers are examples, not universal defaults.

**Implement behaviour from rules.** Stabilise complex UI and states, then use authoritative inputs, defaults, limits and expected outputs. Test each control, combinations and the conversion action. A working main selection does not establish working add-ons. Do not infer prices from noisy captions. Allow layouts to accommodate useful SEO explanations rather than enforcing reference copy lengths. Template facts, testimonials and claims require verified business evidence before publication.

**Fit the still before animation.** Approve slot framing first. Specify what may move, what stays stable, camera behaviour and acceptable transitions. Inspect subject bounds, seams and mobile crops. Mirroring a whole asset can reverse logos or text; preserve brand legibility. Use motion where it serves the visitor, with posters, reduced-motion and playback fallbacks; measure delivery cost. These examples do not require film backgrounds on every page.

**Reconcile the built result.** Update DESIGN.md from approved intent and implemented tokens, assets, components, responsive rules and motion. Preserve source and dependency records. A retrospective prompt aids reconstruction but cannot guarantee identical results in another builder. Keep presentation recordings separate from acceptance evidence. The tutorials do not establish current tool availability, SEO completeness or a substitute for independently verified delivery.
