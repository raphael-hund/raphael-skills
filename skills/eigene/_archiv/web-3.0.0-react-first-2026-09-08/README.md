Der Einstieg ist [SKILL.md](SKILL.md). Für einen neuen Auftrag den [Startprompt](assets/START-PROMPT.template.md) mit den echten Projektdaten füllen. Der Skill unterscheidet vollständigen Bau, Redesign, reine DESIGN.md-Erstellung, Referenzrecherche und gezielte Änderungen. Eine reine Dokumentationsanfrage löst keinen Websitebau aus.

[stack.md](references/stack.md). HTML-first mit Astro-Inseln bleibt nur als [Legacy](references/component-islands.md) für bestehende HTML-Projekte.
