## 2. Hero-Hintergrund (image-1.jpg, oberer Bereich y 544–1100)

Geometrie:
- Vollbreit, `object-fit: cover`, Horizont diagonal von links oben nach rechts unten (Gras-Hang). Wolken oben rechts, Himmel oben links.
- Höhe im Bild ~550 px → ~420 CSS-px; wirkt wie `min-height: 60vh`.

Material:
- Himmel `#12344f` (x 300 / y 600) bis `#113651` (y 750). Wolken-Schatten `#515763` (x 1300 / y 700), Wolken-Licht warm-beige ~`#d8cfa8` (Bildkante rechts, nicht gesampelt → Schätzung).
- Gras `#35472d` (x 500 / y 900), Sonnenkante gelbgrün ~`#b9c94a` (Schätzung anhand Bildeindruck, Region x 400–1400 / y 880–1000).
- Deutliches Filmkorn/Dithering im gesamten Bild (Wolkenränder, Grasfläche). Das Korn steckt im Rasterbild, nicht in CSS. REPORT.md Z. 17 bestätigt die Trennung.
- Vertikaler Fade zu Page: Sample-Spalte x 600: y 1000 `#1b2918` → y 1040 `#0e1712` → y 1100 `#0a0e0f` → y 1160 `#08090b` → y 1180 `#09090b`. Übergang über ~180 Bildpx ≈ 135 CSS-px. Der Fade endet exakt auf Page-Farbe, keine Kante.
- Keine Vignette links/rechts sichtbar, kein Overlay-Tint auf dem Himmel (Himmel behält Sättigung). Der Scrim liegt nur unten.

Nachbau:
```html
<section class="hero">
  <img src="hill.jpg" alt="" class="hero__img">
  <div class="hero__scrim"></div>
  <div class="hero__content">…</div>
</section>
```
```css
.hero{position:relative;min-height:60vh;display:grid;place-items:center;overflow:hidden}
.hero__img{position:absolute;inset:0;width:100%;height:100%;object-fit:cover;object-position:50% 40%}
.hero__scrim{position:absolute;inset:auto 0 0 0;height:36%;
  background:linear-gradient(to bottom,transparent,rgba(9,9,11,.6) 45%,#09090b)}
```
Warum es funktioniert: Der Fade macht Foto und Interface zu einem Material. Die Headline sitzt auf dem hellsten Bildteil (Wolke) → Kontrast ohne Overlay.
Fehler/Slop: Das Korn ist im JPG eingebacken. Bei Retina-Skalierung kann es matschig werden. Ein separates Grain-Overlay wäre kontrollierbarer, ist aber hier nicht belegt.

## 4. Headline (image-1.jpg, y 700–890, zentriert)

Typografie:
- Zwei Zeilen: „Ambient Sounds / For Focus and Calm“. Serif mit hohem Kontrast, kurze Serifen, leicht kondensiert — Charakter wie Tiempos Headline / Newsreader / Instrument Serif (Font nicht belegt).
- Zeilenblock 190 Bildpx für 2 Zeilen → Zeilenabstand ~95 Bildpx ≈ 72 CSS-px. Bei line-height 1,1 → font-size ≈ 64 CSS-px (Schätzung; Bereich 56–68).

Nachbau:

Warum: Serif auf Foto trägt „Ruhe“. Der Kontrast Serif-Headline ↔ Sans-UI unten ist die Hierarchie der Seite.

## 13. Typografie-System

- Display: Serif, 64 / 1.1 / -0.01em, Weiss. H2: gleiche Serif, ~21 px.
- UI: Sans (Inter-artig) 14 px Medium für Labels/Buttons, 13–15 px Regular für Muted, 12 px im Badge.

## 14. Gemeinsamkeiten / Dos / Don'ts

Dos:
- Rasterbild mit Korn als Stimmungsträger, CSS-Scrim nur unten zur Page-Farbe.
- Weisse Serif-Headline direkt auf dem hellsten Bildteil, kein Overlay über dem ganzen Bild.
- UI-Zellen als Border-only auf Page-Farbe, keine Surface-Abstufung.
- Ein CTA durch Inversion (Weiss auf Zinc), keine Akzentfarbe.
- Proof als Zahl fett + Einheit muted in Glas-Pill.

Don'ts:
- Keine Gradient-Headline, kein Glow, kein Text-Shadow.
- Keine Kartenschatten, keine Radius-Inflation (Zellen ≤2 px, Pills 999 px).
- Keine zweite Buntfarbe im UI.
- Keinen Header-Balken über das Foto legen.

## 15. Mobile-Hinweise
