# Graustufen / aggressives SEO

Default-Pfad ist weiß. Dieser Zweig lädt **nur** bei ausdrücklichem Trigger
(„asozial“, „gray-hat“, „Graustufen“, „aggressiv“) **und** Raphaels Go.

Jede Zeile im Output: Taktik · warum Leute sie nutzen · Risiko-Label · Go-Pflicht.
Kein Exploit, kein Account-Hijack, kein Malware, kein Indexing-API-Spam.

## Risiko-Labels (hart)

| Label | Bedeutung |
|---|---|
| Penalty | Ranking-Verlust / manuelle Maßnahme |
| Ban | Property oder Profil fliegt raus |
| rechtlich | Gesetz / Plattform-ToS / Abmahnung |

Google-Spam-Policies (Stand 2026-05-15, Search Central): Cloaking, Doorway,
Expired-Domain-Abuse, Hidden Text/Links, Keyword-Stuffing, Link-Spam,
Scaled-Content-Abuse, Scraping, Site-Reputation-Abuse, Sneaky Redirects,
Thin Affiliation, User-generated Spam, Machine-generated Traffic.

## Weiße Nachbarn, oft verwechselt

- Gästebeitrag mit `rel=sponsored`/`nofollow` = Werbung, kein Graustufen-Zweig.
- Edward-Shorts mit echtem Keyword in der Description = White, wenn Video zum Query passt.
- HeyTony-Hintertür-Keywords (Low-Volume) = White.
- Borja 4–11 interne Links = White.
- Borja Parasite-pSEO auf Medium/GitHub = dieser Zweig, nicht Default.
