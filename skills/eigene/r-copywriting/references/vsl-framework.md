# VSL- & Verkaufs-Copy-Framework

**TLDR:** Ein Verkaufstext (VSL, Long-Form-Ad, Sales-Page) führt den Leser in einer festen
Reihenfolge zum Kauf: Problem spiegeln → EINE Idee → warum sie funktioniert → Beweis →
Einwände weg → EIN nächster kleiner Schritt. Nie ein Feature-Dump, immer eine Geschichte.
Der Hook selbst steht in `cta-framework.md`.

## VSL-Skelett (Reihenfolge = Überzeugungskraft)

1. **Hook / Problem spiegeln** — sofort die Situation des Lesers, nie Selbstvorstellung
   (Details: `cta-framework.md` → Hook).
2. **Big Idea / Promise** — genau EINE Idee, die alles zusammenhält.
3. **Mechanismus / Story** — warum das funktioniert, als Erzählung statt Aufzählung.
4. **Beweis** — echte Case Studies; Testimonial-**Menge** stehen lassen (Volumen ist selbst
   Beweis, auch wenn niemand alle liest).
5. **Einwände & bisherige Versuche entkräften** — DIY, andere Agentur, YouTube, ein Chatbot:
   explizit benennen und wegräumen.
6. **Angebot + EIN nächster kleiner Schritt** — nur den nächsten Klick verkaufen
   („unten mehr erfahren"), nicht direkt „buch deinen Call". Ein CTA-Ziel pro Asset.

## Copy-Grundraster (als Analyse-Linse für Gewinner-Texte)

- **Rule of One:** genau EINE Idee, EINE Story, EINE Emotion, EIN Promise, EIN CTA.
- **Thing → Result → Feeling:** Feature → messbares Ergebnis → Gefühl. Die besten Texte
  verbinden alle drei; die Headline nimmt das stärkste Result + das stärkste Feeling.
- **Customer-Avatar:** je 3 Hin-zu-/Weg-von-Motivatoren, jeden mit „Warum?" und „Was dann?"
  vertiefen; bisherige Lösungsversuche adressieren.

## Identitäts-Commitment (Cialdini) — Thank-You- & Nurture-Texte

**Muster:** erst eine **Identitätsaussage**, der der Lead zustimmt, DANN die Policy/Regel.
Wer vorher zustimmt, verhält sich danach konsistent.

- **Zwischen-/Danke-Seiten:** Abschluss-Wörter („Danke", „Glückwunsch", „Geschafft")
  vermeiden — sie schließen die Schleife im Kopf, der Nutzer schließt den Tab, obwohl noch
  ein Schritt offen ist. Stattdessen „Fast geschafft" / „Letzter Schritt" + Fortschritt.
  Erst ein Identitäts-Textblock (Zustimmung), dann die No-Show-/No-BS-Policy.
- **Branchenweise anpassen:** die Identitätsaussage muss zur Zielgruppe passen, keine
  Blaupause 1:1 kopieren.
- **KPI = Show-Rate** (echtes Verhalten der Leads), **kein Judge-Score**. Der Text ist gut,
  wenn mehr Leute wirklich erscheinen — nicht, wenn ein Modell ihn „schön" findet.

## Nurture-Framing

- **CTAs immer aus Empfängerperspektive** („das hilft DIR"), nie aus Absenderperspektive
  („wir würden uns freuen"). Häufigste unausgesprochene Sorge früh adressieren (z. B. per
  kurzem Video), sonst erfinden Menschen die schlechteste Geschichte selbst.
- ⚠️ **Hammer-Sequenz** (mehrere Mails am ersten Tag, hohe Frequenz) nur für **bereits
  gebuchte** Leads — die wollen Infos. Bei **kalten** Leads ist das Spam und funktioniert
  NICHT. Feste Abbruchregel: Wer sich über die Frequenz beschwert, kommt raus. **Grauzone —
  bewusst als solche markieren.**

## LLM-Copy-Hinweis

Nie „schreib mir eine Anzeige für X" an ein Modell geben — es regrediert zum Mittelwert und
liefert generische Copy ohne Committed Language und ohne Filter. Stattdessen erst **2–3
eigene, funktionierende Beispiele + Begründung** („ich schrieb X, weil Y") als Referenz
geben. Notfalls schnell einen schlechten Entwurf hinschreiben und dann remixen — leichter,
als sofort perfekt zu formulieren.
