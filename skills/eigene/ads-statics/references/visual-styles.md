# Visual Styles für Statics

Acht wiederkehrende Rahmen für statische Ad-Creatives. Der Style ist der Rahmen, die
Copy-Bauform ist der Text darin. Ein Brief wählt IMMER zuerst den Style, dann die Copy.
Siehe `copy-bauformen.md` für die Text-Ebene, `brief-schema.md` für das Brief-Format.

**Copy-Form-Regel:** Der Angle-Text ist die Botschaft. Wie sie gesprochen wird, entscheidet
der Rahmen: Karte = Schlagzeile, Post = Postsprache, Chat = Chatsprache, Selfie =
Storysprache. Beim Rendern wird die Copy in die Rahmen-Sprache übersetzt, nie 1:1 aus
dem Angle-Text übernommen.

## Was eine geile Static tut

Vier Tests, bevor ein Brief rausgeht:

1. **Qualifier + Zahl im ersten Blick.** Wer gemeint ist und was rauskommt, muss in unter
   einer Sekunde lesbar sein. Kein Scrollen, kein Zoomen, kein Nachdenken.
2. **Clarity ODER Curiosity — nie beides, nie keins.** Entweder ist sofort klar, was
   angeboten wird (Clarity), oder es öffnet bewusst eine Lücke, die der Klick schliesst
   (Curiosity). Im Brief ankreuzen, welche der beiden.
3. **Native oder bewusst laut.** Entweder sieht die Static aus wie Content im Feed (native)
   oder sie ist sichtbar Werbung und steht dazu (laut). Beides funktioniert. Die Mitte
   nicht (siehe Punkt 4).
4. **Nie die polierte Mitte.** U-Kurve: minimaler Aufwand (bewusst roh, 5-Minuten-Look)
   ODER sehr hohes Produktionsniveau performt. Die generische Canva-Mitte — halb Werbung,
   halb Content — wird sofort als Ad erkannt und übersprungen.

## Safe-Zone und Aufbau

- **Im 9:16 anlegen, Kern im zentrierten 1:1.** Meta croppt manche Placements ca. 20 %
  oben und unten ab. Headline, Zahl und CTA gehören in die mittlere Zone, nie an den Rand.
- **Hierarchie über drei Stellhebel, in Reihenfolge:** Grösse (grösstes Element zuerst
  verarbeitet) → Kontrast (Auge wandert zur Abweichung) → Weissraum (lenkt weg vom
  Unwichtigen). Gilt für jeden Style beim Feinschliff.
- **Setting = ICP-Alltag, nicht Marken-Hochglanz.** Handwerker-ICP + steriles Büro verliert
  gegen Handwerker-ICP + Werkstatt. Location nach dem Alltag der Zielgruppe wählen.

## Die 8 Styles

### S1 — Helle Typo-Karte (Text-only) *(produzierbar ohne Material)*
Fast weisser oder schwarzer Grund, viel Weissraum, kein Foto. Headline dominant,
Ergebnis-/Filterzeile in Akzentfarbe, CTA-Block unten. 1:1 + 4:5.
Copy-Form: Schlagzeile, max. 5 Zeilen sichtbar.
Billigster Angle-Test: eine Static pro Angle, keine Produktion nötig. Bei MAKE die beste
eigene Kosten/Termin-Rate.

### S2 — Native-UI / Post-Karte *(produzierbar ohne Material)*
Onscreen-Copy als Screenshot eines eigenen Posts: Post/Tweet/Notes-Chrome, Profilbild,
Name, Post-Text. Hell oder dunkel als Kontrast-Variante. Genau ein Profilbild.
Copy-Form: Postsprache, erste Person, Zeilenumbrüche wie ein echter Post, keine
Werbe-Interpunktion.

### S3 — Testimonial / Award-UGC *(braucht Kundenmaterial)*
Echtes Kunden- oder Betriebsfoto, darüber eine Karte mit Zahl + Name + Zeitraum, auf den
ersten Blick lesbar. Kein Stock, kein Studio-Polish: Polish untergräbt die Glaubwürdigkeit.
Person muss demografisch zur echten Klientel passen — Matching ist ein eigener
Erfolgsfaktor, unabhängig von der Zahl.
Copy-Form: wie ein Kunden-Post, nie Agentur-Sprech.

### S4 — Chat-Screenshot *(braucht echten Vorgang)*
Echter Handy-Screenshot: eingehende Anfrage, Chat-Verlauf oder Notification. Darunter
eine Zeile im Post-Look. Retargeting-Default.
Copy-Form: Chatsprache, kurz, unperfekt, echt.
**Nur echte, anonymisierte Vorgänge. Nie erfunden** (Grounding-Pflicht, siehe unten).

### S5 — Schild / Requisiten *(braucht Drehtag-Material)*
Person hält ein Schild mit der Botschaft, echte Location statt Studio. Gesicht
angeschnitten ist ok: Fokus bleibt das Schild. Handschrift-Wirkung.
Copy-Form: max. 5 Zeilen, wie handgeschrieben.

### S6 — Story-Selfie + Bubbles *(braucht Selfie-Material)*
Ungeposetes Selfie aus dem Arbeitsalltag. Zonen von oben nach unten:
Top-Callout (Rolle + Schwelle) → ungeposetes Selfie → Zahl + Zeit in dunkler Bubble →
optional ein Proof-Element → CTA-Bubble.
Story-Font, genau ein Akzent. Sieht aus wie eine gespostete Story, nicht wie eine Anzeige.

### S7 — Device / Dashboard *(braucht echten Screen)*
Echte Arbeitsumgebung sichtbar: Laptop, Tablet oder Handy mit dem echten Tool oder
Dashboard. Eine bis zwei Callout-Boxen dazu. Zahlen im Screen sehen aus wie im echten UI.
**Nur echte Screens. Nie ein gebautes Fake-Dashboard.**
Copy-Form: knapp, sachlich, zahlenfirst.

### S8 — Quiz / Map / Product *(produzierbar ohne Material)*
Pain- oder Curiosity-Frage oben, darunter Selector-Kacheln, Karte oder Produktbild,
darunter Check oder CTA-Button. Cold-Traffic-Style, nicht Retargeting.
Copy-Form: eine Frage plus wählbare Antworten — der ICP qualifiziert sich durch die
Auswahl selbst (z. B. Kacheln nach Betriebsgrösse).

## Hook × Style-Matrix

| Hook | Styles |
|---|---|
| Callout (Selbstfilter) | S6, S1, S3 |
| Proof (Beleg) | S4, S3, S7 |
| Offer / Preis | S1, S2, S7 |
| Curiosity | S8 |
| Pain | S1, S2 |
| Garantie | S1, S6 |

## Funnel-Zuordnung

| Funnel | Styles |
|---|---|
| ToF / Cold (nativ) | S2, S6, S8 |
| Mid (Vergleich, Before/After) | S8, S3, S2 |
| BoF / Retargeting (Offer, Proof) | S3, S5, S7, S1, S4 |

Chat (S4) und Proof-first laufen primär im Warm-Pool. Kein Quiz im Retargeting.
Style ohne Funnel-Zuordnung ist ein halber Brief.

## Proof-Regel (hart)

Proof muss echt sein. KI wird nie für Fake-Chat, Fake-Case oder Fake-Dashboard benutzt.
Fehlt das Material: Brief in die Warteliste, nicht ungegroundet bauen.

## MAKE-Spezifisch

CTR über 2 % ist ein Warnsignal, kein Erfolg: schwache Filterung zieht Anti-ICP-Klicks.
Gilt style-übergreifend, besonders bei S1 und S2 mit reisserischer Copy.

## Gotchas

- **S3/S4/S7 ohne echtes Material ist ein Stopp, kein Kompromiss.** Kein Stock-Ersatz,
  keine Mock-Chats, keine Fake-Screens.
- **KI-Optik ist ein eigenes Risiko in der Test-Phase**, nicht nur ein
  Skalierungs-Kompromiss: hohe CTR bei schlechterer Conversion-Qualität möglich.
